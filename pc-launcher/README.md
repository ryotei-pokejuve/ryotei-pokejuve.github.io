# RYOTEI WIRED（Windows）

スマホ版ランチャーの「WIRED」の世界を、Windowsのデスクトップで使えるようにしたランチャー。描画の部品（`Wired.java`・`Pix.java`・リテの演出）はスマホ版と共通。

## インストール

1. https://github.com/ryotei-pokejuve/ryotei-pokejuve.github.io/releases/tag/pc-launcher-latest から `RYOTEI-WIRED.zip` をダウンロード
2. 展開して、`RYOTEI-WIRED` フォルダの中の `RYOTEI-WIRED.exe` を起動（Javaは同梱しているので別に入れなくてよい）
3. 「WindowsによってPCが保護されました」と出たら「詳細情報 → 実行」（署名していない自作アプリのため）
4. メニューの「スタートアップ：ON」で、PCを起動したときに自動で開くようになる

`pc-launcher/` か共通の描画部品を変更してpushすると、GitHub Actionsがビルドして上のリリースを最新版に置き換える。

## 操作

| 場所 | 操作 | 動き |
| --- | --- | --- |
| ホーム | カプセルをクリック | 選ぶ（右に名札が出る） |
| ホーム | 選んだカプセルをもう一度クリック | 接続（アプリを起動して、ランチャーは最小化） |
| ホーム | 空のカプセルを2回クリック | ディレクトリから選んでつなぐ |
| ホーム | リテを2回クリック・文字を打つ | 検索（日本語入力もできる。Enterでいちばん上に接続） |
| ホーム | ホイール・横ドラッグ | 軌道を回す |
| ホーム | ← →・タイトルの < > | LAYER 01〜05 を行き来（レイヤーごとに10個） |
| どこでも | 右クリック | その場のメニュー（つなぎかえ・きりはなす・ファイルの場所） |
| どこでも | ファイルやフォルダをドロップ | ディレクトリに取りこむ（カプセルの上なら、そのままつなぐ） |
| DIR | ダイヤル・ホイール | チャンネル（頭文字）で絞り込み・壁を送る |
| どこでも | Esc | 戻る（ホームでは最小化） |

アプリ一覧は、スタートメニューとデスクトップのショートカットから自動で作る。設定は `%APPDATA%\RyoteiWired\settings.properties` に保存される。

## 構成

- `src/.../PcEngine.java` … 画面と操作（横長に組み直したホーム・DIR・検索・メニュー）
- `src/.../PcMain.java` … 枠なし全画面ウィンドウ、マウス・キーボード・ドロップ、日本語入力用の見えない入力欄
- `src/.../PcApps.java` … ショートカットの収集・アイコン・起動・設定の保存・スタートアップ
- `src/.../PcSound.java` … 矩形波の効果音
- `tools/PcPreview.java` … Windowsなしで画面を連番PNGに書き出す確認ツール
- `build.sh` … jar を作る（スマホ版の描画部品と `android.graphics` の代わりのクラスを一緒にコンパイル）
