Turn 1 — 2D mode, two directions

架空の観測端末として操作するサイト UI

参考資料からは意匠ではなく構造だけを抽出しました。二重の縁で立ち上げる窓、上段＝状態／中段＝操作対象／下段＝常設メッセージ窓の三段、カーソル記号と反転を併記する選択状態、分類色を小さなチップに閉じ込める符号化、離散ピップによる数値表示、そして十字キー六操作で全要素に到達できるナビゲーション。この六つを軸に、1a（暗色・線ベース・高密度）と1b（明色・面ベース・余白多め）の二案を用意しています。どちらも4画面（メニュー／標本／区域図／記録）が実際に遷移し、枠をクリックしてから方向キー・Enter・Esc で操作できます。
