# RYOTEI LAUNCHER（Android）

GBAのRPGで遊んでいるような見た目の、Android用ホームアプリ（ランチャー）。

- **ホーム＝タウンマップ**：オリジナルの地方の地図に、お気に入りアプリ10個が「まち」として並ぶ。タップでカーソルを合わせると上に町の名前、もう一度タップで主人公がその町へ飛んでアプリが起動する
- よく使う町は「タウン」から「シティ」に育ち、地図上の印も大きくなる。あき地（灰色）を選ぶと新しい町（アプリ）を地図に載せられる
- 地図の真ん中の「ネットシティ」は電脳世界の入口で、チップフォルダ（アプリ一覧）が開く
- 上部は時計と電池残量（HPバー）、下部はメッセージウィンドウ（1文字ずつ出る。2行に入らない時は▼が出て、タップで続きへ）。選んでいる項目の長い名前は横に流れて最後まで読める
- **メニューとアプリ一覧は電脳風**：アプリ一覧は「チップフォルダ」。名前の頭文字がチップコードになり、起動すると「プラグイン！ ○○ トランスミッション！」
- 効果音は矩形波のピコピコ音（メニューでON/OFF）
- **もうひとつの世界「WIRED」**（メニューの「せかい」で切り替え）：藍色の暗がりの真ん中に古いCRTモニターがあり、紫のカプセル（お気に入りアプリ）が傾いた楕円軌道でゆっくり回る。カプセルにはアプリ名が出て（長い名前は流れる）、選んだアプリはティール単色でモニターに映る。もう一度タップで接続（起動）、モニターをタップするとディレクトリ（アプリ一覧）。ディレクトリは古いモニターが積まれた壁で、下の周波数ダイヤルを回すと頭文字（A〜Z・あかさたな…）のチャンネルに合わせられる。タップしたモニターに吸い込まれるようにアプリが開く。横ドラッグで軌道を回せる。タイトル左右の < > で LAYER 01〜05 を行き来でき、レイヤーごとに別のアプリを10個ずつつなげる（LAYER 01 はGBAのタウンマップと共通）。しばらく触らずにいると、どこからか声がする
- **リテ（RITE）**：WIREDの真ん中に、画面の向こう側にいるようなナビゲーターが立つ（走査線・横ずれ・色のにじみ・ときどき途切れる）。2回タップすると検索になり、キーボードで打った文字でアプリを絞り込んでモニターの壁に映す。絵は `app/src/main/assets/images/rite_full.png`・`rite_bust.png` に置く（無ければ代わりにCRTモニターが立つ）

画像・フォント以外の素材はすべてコードで描画しており、既存ゲームの画像は使っていない。フォントは [DotGothic16](https://github.com/fontworks-fonts/DotGothic16)（SIL Open Font License、`app/src/main/assets/fonts/OFL.txt`）。

## インストール

1. Androidで https://github.com/ryotei-pokejuve/ryotei-pokejuve.github.io/releases/tag/launcher-latest を開き、`ryotei-launcher.apk` をダウンロード
2. 開いてインストール（「提供元不明のアプリ」の許可を求められたら許可）
3. ランチャーを開いてメニューの「メインの ホームに する」を押すと、Androidの確認が出るので許可する（設定の「標準のアプリ → ホームアプリ」からでも切り替えられる）

`android-launcher/` 以下を変更してpushすると、GitHub Actionsが自動でAPKをビルドして上のリリースを最新版に置き換える。

## 操作

| 場所 | 操作 | 動き |
| --- | --- | --- |
| タウンマップ | まちをタップ | カーソルを合わせる（名前と説明が出る） |
| タウンマップ | 選んでいるまちをもう一度タップ | そのまちへ飛ぶ（アプリ起動） |
| タウンマップ | まちを長押し | とぶ / いれかえる / けす / アプリじょうほう |
| タウンマップ | あき地を選んでもう一度タップ | チップフォルダから選んで地図に載せる |
| タウンマップ | ネットシティ・上にスワイプ・APPS | チップフォルダ（アプリ一覧） |
| タウンマップ | MENU・地図の外を長押し | メニュー（「いつもの ホームへ」で元のホーム画面へ一時的に移れる） |
| タウンマップ | 下にスワイプ | 通知を開く |
| タウンマップ | 時計をタップ | 時計アプリ |
| チップフォルダ | タップ / 長押し | プラグイン（起動） / ホームに建てる・アプリ情報・アンインストール |
| チップフォルダ | 左右スワイプ・タブ | すべて / よくつかう / さいきん |
| チップフォルダ | 右端をドラッグ | 早送りスクロール |

## 構成

- `Engine.java` … 画面・操作・演出のまとめ役。約270ドット幅の低解像度キャンバスに描き、整数倍で拡大表示する
- `Wired.java` … WIREDの世界（背景・軌道とカプセル・モニター・グリッチや砂嵐の演出）
- `TownMap.java` / `Sprites.java` … タウンマップの地形（文字列で描いた地図）・道・まちの印と、主人公のドット絵
- `Scenery.java` / `Theme.java` / `Pix.java` … 背景タイル、配色、ドット描画の道具
- `HomeActivity.java` / `GameView.java` / `AndroidHost.java` / `Sfx.java` / `PixelIcon.java` … Android側（アプリ一覧・起動・電池・効果音・アイコンのドット絵化）
- `tools/preview/` … Android SDKなしで、台本どおりに操作した画面を連番PNGに書き出す確認ツール（`sh tools/preview/run.sh 出力先 [GBA|WIRED]`。動画化の方法はスクリプト内に記載）

署名鍵はリポジトリに置いていない。GitHub Actionsが初回ビルドで鍵を作ってキャッシュに保存し、以降はそれで署名する（同じ鍵なので上書き更新できる）。キャッシュは7日間ビルドが無いと消えることがあり、その後のビルドは鍵が変わって「アプリが競合」と出る（いったんアンインストールすれば入る）。確実にしたい場合は自分で鍵を作り、リポジトリの Settings → Secrets に `LAUNCHER_KEYSTORE_B64`（keystoreをbase64にしたもの、エイリアスは `ryotei`）と `LAUNCHER_KEYSTORE_PASSWORD` を登録する。
